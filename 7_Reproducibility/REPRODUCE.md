To reproduce this project, please clone this directory and simply run the main script by the name `ME701.py` in the `3_code/` directory to get the simulation results obtained (in the `4_Data_results/` directory)

The reference values and the baseline used are also given as a text file in the `4_Data_results/Input data/` directory.

**Expected outcomes**
After running the script you would receive the optmized vs baseline values printed in the terminal along with the plots of Life vs the chosen design parameters of module m, face width b, and gear ratio i and iterations will also be obtained. These are included in the `4_Data_results/Processed data/` and `4_Data_results/plots/` directoryies.

For more details refer to the `README.md`.
